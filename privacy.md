# Privacy Policy

*Last updated: 16 October 2026.*

This page is published by Christopher O.H. Williams. This policy covers **ocw-gmail**, a private software tool I built for my own use, and the Google account data it accesses.

### Who uses ocw-gmail

ocw-gmail is not a public product or service. Only I use it, and only with Gmail accounts that belong to me. Nobody else can sign up for it or use it.

### What it accesses

With my permission, given through Google's sign-in screen, ocw-gmail can:

- read and search the email in my own Gmail accounts;
- create draft emails in those accounts;
- send an email or change labels, but only when I explicitly approve that specific action.

### How the data is used

I use ocw-gmail to search my email, to write private summaries of it for my personal records, and to draft replies. The AI assistants I use (such as Claude, Gemini and Codex) may process email content on my behalf to do this. The summaries are stored in my private, access-controlled records.

### What it does not do

- It does not sell, rent or share Google user data with anyone.
- It does not use Google user data for advertising.
- It does not use Google user data to develop, improve or train general-purpose AI or machine-learning models.
- No person other than me can see the data, except where the law requires it.

### Storage and security

The sign-in credentials that let ocw-gmail access my accounts are stored encrypted on my own computer and are never published. Email itself stays in Gmail. Only the summaries I choose to keep are stored, in my private records.

### Google API Services User Data Policy

ocw-gmail's use and transfer of information received from Google APIs will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

### Revoking access

Access can be removed at any time at [myaccount.google.com/connections](https://myaccount.google.com/connections). Removing it stops ocw-gmail from reading any further email.
